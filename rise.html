🔥 떡상 영상 찾기

오래전에 터진 영상을 찾아 쇼츠 아이디어로 — 구독자 대비 조회수 배율로 정렬

API 키 받는 법 (무료)
  1. console.cloud.google.com 접속 → 상단에서 새 프로젝트 만들기
  2. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → "YouTube Data API v3" 검색 → 사용
  3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키 → 나온 키 복사
  4. 위 칸에 붙여넣고 저장 (이 기기 브라우저에만 저장돼요)
하루 무료 사용량은 10,000이고, 매일 오후 4~5시(한국 시간)에 초기화됩니다. 키워드 검색은 1번에 약 100, 채널 분석은 1번에 10~30 정도 써요.
채널 분석에서는 '채널 평균 대비' 배율(그 채널의 보통 영상보다 몇 배 터졌는지)로 정렬돼요.
