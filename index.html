카드뉴스 스튜디오

기사 3개를 넣으면 제미나이가 제목 · 배경 그림 · 인스타 본문까지 만들어요.

설정

API 키는 이 컴퓨터의 브라우저에만 저장되고, 제미나이 서버로만 보내져요. 키 발급: aistudio.google.com/apikey (본계정으로 로그인)

STEP 1글감 넣기

링크만 넣어도 되고, 링크가 안 읽히면 본문을 붙여넣으세요. 본문이 있으면 본문을 우선 사용해요.

STEP 2제목 고르기

제목을 누르면 이미지에 들어가요. 오른쪽 릴스에 넣기를 누른 순서대로 릴스 장면이 돼요. [대괄호] 안 단어는 강조색이에요.

STEP 3인스타 본문

스타일을 고르고 다듬은 뒤 복사해서 붙여넣으세요.

STEP 4릴스 영상

지금 카드의 그림과 제목으로 9:16 세로 영상을 만들어요. 목소리는 저장한 영상을 브루에 넣어 붙이세요.
